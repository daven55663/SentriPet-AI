SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。

**2.0 起 Windows、macOS、Linux 用同一個版本**。原本的 Windows 專用版本（WPF）已經退役，需要的話仍可在 [v1.4.0](https://github.com/daven55663/SentriPet-AI/releases/tag/v1.4.0) 下載。

## 下載

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.0.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.0.0-osx-arm64.zip` | 解壓縮，把 `SentriPet.app` 拖到「應用程式」 |
| macOS Intel | `SentriPet-2.0.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.0.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

每個檔案都已包含執行需要的一切，不需要另外安裝 .NET。

- **Windows**：出現「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」（程式沒有數位簽章）。
  從 1.x 升級：在右鍵選單按「結束」，把新的 `SentriPet.exe` 放到原本的資料夾（預設 `%LOCALAPPDATA%\Programs\SentriPet`）再開啟即可，設定會保留。
- **macOS**：App 沒有 Apple 開發者簽章，第一次請在 `SentriPet.app` 上按右鍵 →「打開」，
  或執行 `xattr -dr com.apple.quarantine /Applications/SentriPet.app`。
- **Linux**：需要 X11 或 XWayland 桌面；GNOME 顯示系統匣圖示需要「AppIndicator and KStatusNotifierItem Support」擴充。

完整的安裝與使用說明見 [README](https://github.com/daven55663/SentriPet-AI#readme)。

## 這一版的變化

- Windows 也改用跨平台版：和 1.x 一樣的 8 種造型、詳情卡、設定頁、提醒與「快用掉」催促、多國語言。
- 系統匣／選單列圖示畫成小果凍，高度 = 最低的剩餘額度，AI 工作中多一個藍點（三個系統都有）。
- Windows 的通知以 SentriPet 的名義發出，開始選單也會有 SentriPet。
- Linux：全螢幕時自動躲起來；桌寵的眼睛跟著整個螢幕上的滑鼠。macOS 的眼睛也改成跟著全域滑鼠。
- 右鍵選單補上「透明度」與「每天隨機換一個」造型。
- 修正：沒有設定「主螢幕」的 Linux 環境裡，桌寵第一次開啟會跑到左上角。
- 記憶體約 110–130 MB，整體 CPU 不到 1%。
- 自動測試：核心 354 項、桌寵 70 項，每次都在 Windows、macOS、Linux 上跑，並在三個系統上實際開啟程式檢查；
  每個安裝檔發佈前都會先跑一次自己的自我測試。

## 已知限制

- 還沒有在實體的 Mac／Linux 電腦上長時間試用，歡迎回報問題。
- Claude 桌面版沒有 Linux 版，Linux 上讀不到 Claude 的方案用量（#9）。
- Windows 上推算值前面的記號顯示為「~」（macOS／Linux 為「≈」）。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
