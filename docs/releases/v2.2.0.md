SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.2.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` → `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.2.0-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI` → `brew install --cask sentripet` |
| macOS Intel | `SentriPet-2.2.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.2.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`；自己下載的版本，結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **AI 做完或在等你時提醒**（#14）：設定 → AI 服務 開啟後，Claude Code 做完較長的任務（超過 30 秒）、要你確認或在等你回覆時，
  以及 Codex 做完時，那隻桌寵會跳起來告訴你（可以同時跳通知）。會在 `~/.claude/settings.json` 加上 hooks、
  在 `~/.codex/config.toml` 設定 `notify`：修改前先備份，你原本的 hooks 與 notify 程式照常運作，關掉就還原。
- **用完預測**（#15）：額度正在使用時，懸停卡片會顯示「照目前速度約 15:40 用完」，剩 45 分鐘時桌寵提醒一次。
- **額度利用率週報**（#16）：每週／每月額度重置時，桌寵會說這一期用掉多少；設定頁可以看最近 8 期的長條圖與平均。
  電腦關機時剛好跨過重置也會補記。
- **勿擾時段**（#17）：設定 → 提醒 可設時段與星期；右鍵選單可「暫停提醒 1 小時」。這段時間不跳通知、桌寵不主動說話。
- **CPU 用量大幅降低**（#8）：平常狀態下，賽車儀表從單核 26.8% 降到 2.1%、極簡玻璃 15.3% → 2.3%、便利貼 14.7% → 1.8%、
  駭客終端 14.1% → 1.0%。改法：卡片陰影改成不用每格重新模糊的畫法、沒變的東西不重畫、平常降到每秒約 16 格，
  有動靜時才恢復順暢；隱藏時完全停止。
- 新增 Scoop、Homebrew 安裝方式；README 改成英文為主（另有繁體中文版），附示範動畫。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
