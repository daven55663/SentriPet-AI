SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。

## 下載

| 系統 | 檔案 | 說明 |
|---|---|---|
| Windows（原本的 WPF 版） | `SentriPet-1.4.0-windows-wpf.zip` | 解壓縮後執行 `SentriPet.exe`，Windows 10／11 內建的 .NET Framework 即可 |
| Windows（跨平台版） | `SentriPet-1.4.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，不需要另外安裝 .NET |
| macOS Apple 晶片 | `SentriPet-1.4.0-osx-arm64.zip` | 解壓縮，把 `SentriPet.app` 拖到「應用程式」 |
| macOS Intel | `SentriPet-1.4.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-1.4.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

**macOS 第一次開啟**：這個 App 沒有 Apple 開發者簽章，第一次請在 `SentriPet.app` 上按右鍵 →「打開」，
或在終端機執行 `xattr -dr com.apple.quarantine /Applications/SentriPet.app`。

## 這一版的新功能

- **macOS 與 Linux 版**（跨平台版，用 Avalonia 重寫畫面）：8 種造型、懸停詳情卡、設定頁、提醒與「快用掉」催促、
  系統匣、開機啟動、系統通知、滑鼠穿透都已完成；記憶體約 110 MB。
- **多國語言**：繁體中文、简体中文、English、日本語、한국어，預設跟隨系統語言，右鍵選單「語言 · Language」可隨時切換。
- 每週額度快重置、卻還剩很多時，桌寵會著急地催你用掉（表情、閃爍的進度條、通知）。
- 自動測試：Windows 版 410 項、核心 354 項、跨平台桌寵 37 項，每次都在 Windows、macOS、Linux 上跑；
  每個安裝檔發佈前都會先跑一次自己的自我測試。

## 已知限制

- 跨平台版還沒有在實體的 Mac／Linux 電腦上長時間試用，歡迎回報問題。
- macOS／Linux 沒有「全螢幕時自動躲起來」；macOS 上眼睛只在滑鼠經過時跟著看。
- Claude 桌面版沒有 Linux 版，Linux 上讀不到 Claude 的方案用量（#9）。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
