SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.7.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` 後 `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.7.0-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI`、`brew trust daven55663/sentripet` 後 `brew install --cask sentripet`（Homebrew 現在要求先信任第三方 tap） |
| macOS Intel | `SentriPet-2.7.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.7.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：2.7.0 是第一個會自己檢查新版本的版本，所以這一次仍須手動更新——Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`（Homebrew 若要求，先執行一次 `brew trust daven55663/sentripet`），
自己下載的版本結束舊版後用新檔案覆蓋即可。之後的版本推出時，桌寵會自動詢問是否更新。設定都會保留。

## 這一版的變化

- **自動更新**（#39）：啟動後不久與之後每天，SentriPet 會向 GitHub 查詢一次最新的版本號（不附帶任何用量資料）；有新版本時跳出視窗列出這一版的變化，
  可選「現在更新」、「稍後」或「略過這個版本」。用 `install.cmd` 安裝或自行解壓縮的 Windows 版會下載新版、核對 GitHub 公布的 SHA-256 後替換並自動重新開啟；
  Scoop、winget、Homebrew 安裝的版本交由套件管理器更新；macOS 與 Linux 自行下載的版本則開啟發佈頁。預設開啟，可在設定頁「一般」關閉，
  也可以隨時按「立即檢查」或系統匣選單的「檢查新版本」。說明見 [README](https://github.com/daven55663/SentriPet-AI/blob/main/README.zh-TW.md#自動更新)。
- **自訂造型可以播放 GIF 動畫**（#38）：狀態圖片可以是 GIF，桌寵與狀態圖片編輯器都會循環播放；圖片元素的 `speed` 可依圖片或狀態調整播放速度，
  只播一次的 GIF 每格最多停 4 秒，讓桌寵持續動。GIF 只解碼一次並縮到顯示大小的兩倍保存，大張的 GIF 也不會占太多記憶體。
- **桌面版與終端機登入不同的 Claude 帳號**（#36）：Claude Code 的每一則回覆都記有來源（桌面版或終端機），開啟設定「終端機是另一個 Claude 帳號」後，
  桌面版與終端機各有一隻桌寵、各自計算用量；終端機那一隻使用狀態列的官方數字，兩次官方數字之間用自己帳號的紀錄推算。
- **修正：狀態列的數字時間錯置**（#36）。狀態列在開著的對話裡重畫時，帶的是那個對話最後一次回覆時的數字，先前卻記成重畫的時間，造成較舊的數字蓋掉新的；
  現在以對話最後一則回覆的時間為準。
- **偵測 Gemini 桌面版**（#37）：除了 Gemini CLI，也會偵測 Windows 的 Gemini 桌面版。桌面版本機沒有用量資料，所以和其他沒有用量來源的工具一樣列在設定頁，可用外掛接上。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9711） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 4.16336.0（Claude Code 2.1.317）、Codex 26.1027——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 863 項、桌寵自我測試 158 項、實機煙霧測試 8 項，另在這台電腦實際跑過一次完整的自我更新（下載、驗證、替換、重新開啟）；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證；檢查新版本時只向 GitHub 查詢最新的版本號。
