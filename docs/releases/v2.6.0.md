SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.6.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` 後 `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.6.0-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI` 後 `brew install --cask sentripet` |
| macOS Intel | `SentriPet-2.6.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.6.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`；自己下載的版本，結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **狀態圖片編輯器**（#34）：自訂造型不必再手動改 `theme.json` 來換圖。在設定頁「造型」分區的「自訂造型」按「編輯狀態圖片」，
  左邊是造型資料夾的圖庫（子資料夾各自一組），右邊是各種狀態；把圖拖到狀態上、先點圖再點狀態，或從檔案總管把圖片拖進來，
  桌寵就會立刻換上。選擇存在造型資料夾的 `states.json`，作者的 `theme.json` 不會被改動，按「還原」就回到原本的圖。
  使用方式寫在 [README](https://github.com/daven55663/SentriPet-AI/blob/main/README.zh-TW.md#用拖曳替狀態換圖狀態圖片編輯器)。
- **新狀態「AI 做完了」**（#34）：Claude Code 或 Codex 做完一件比較久的事之後 30 秒，那隻桌寵改用造型的「做完了」圖片與文字。
- **新狀態「催你快用」**（#35）：每週或每月額度快重置卻還剩不少時（與「快用掉」提醒同樣的時機），桌寵改用造型的「催你快用」圖片。
  優先順序依序為 AI 做完了、正在工作、催你快用、心情；兩個新狀態都是選填的，造型沒有準備圖片時照舊顯示。
- **修正：Codex 即時查詢在較舊的 Codex 上失敗**（#30）。VS Code 擴充附帶的較舊 Codex 不接受查詢額度時的參數，現在會改用不帶參數的方式再問一次。
- **Claude 推算的說明更清楚**（#31）。剛安裝、還沒有任何校準時，懸停卡片會說明要等 Claude 桌面版下一次記錄用量；
  5 小時額度從 Claude Code 的第一則回覆起算時，註明網頁與聊天的用量看不到、可能會更早重置；每週重置時間推算不出來時，提示可以在設定裡填。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9711） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 2.42304.0（Claude Code 2.1.299）、Codex 26.1013——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 762 項、桌寵自我測試 149 項、實機煙霧測試 9 項；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
