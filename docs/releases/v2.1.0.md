SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。

## 下載

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.1.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.1.0-osx-arm64.zip` | 解壓縮，把 `SentriPet.app` 拖到「應用程式」 |
| macOS Intel | `SentriPet-2.1.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.1.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

每個檔案都已包含執行需要的一切。從 2.0 升級：結束舊版後用新檔案覆蓋即可，設定會保留。
macOS 第一次開啟請在 `SentriPet.app` 上按右鍵 →「打開」（沒有 Apple 開發者簽章）。完整說明見 [README](https://github.com/daven55663/SentriPet-AI#readme)。

## 這一版的變化

- **連接 Claude Code 狀態列（官方用量）**（#9）：在 設定 → AI 服務 開啟後，Claude Code 每次回覆都會把官方的用量與重置時間交給 SentriPet。
  - **Linux 也讀得到 Claude 的用量了**（Linux 沒有 Claude 桌面版，靠這個方式）。
  - Windows／macOS 上，Claude 的重置時間改用官方的，不再是推算值。
  - 會修改 `~/.claude/settings.json`（修改前先備份）；你原本的狀態列照常顯示，關掉選項就原封不動還原。
  - 需要 Claude Pro 或 Max 訂閱；數字在使用 Claude Code 時更新。
- **右鍵選單整理**：「換造型」與「今天心情如何？」兩個重複的選單合併成一個「換造型」，每種造型旁邊標著心情，
  「交給命運吧（隨機）」與「每天隨機換一個」也放在一起；選單最上面的用量摘要改成每個 AI 一行，不會再被截斷。
- README 的截圖全部改成 2.x 版本的畫面。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
