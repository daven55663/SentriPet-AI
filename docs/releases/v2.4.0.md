SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.4.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` → `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.4.0-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI` → `brew install --cask sentripet` |
| macOS Intel | `SentriPet-2.4.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.4.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`；自己下載的版本，結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **養成與成就**（#23）：把額度用好，桌寵就會成長。每期週／月額度結束時依利用率給經驗值——用到 90% 以上**而且沒有太早用完**最多，
  太早用完、卡了一整天的反而比用到 70～90% 還少，重點是有計畫地用，不是用越多越好；每天打開也會加一點。
  果凍桌寵升級會戴上蝴蝶結、星星徽章、小花、皇冠，Lv 10 變成金色；另外有 10 個成就。第一次開啟時，週報裡已經有的紀錄也會算進去。
  設定 →「成長與成就」可以看經驗值、成就，也可以關掉。
- **自訂造型**（#24）：用圖片和 `theme.json` 做自己的造型，依心情換圖、放文字／進度條／圓環，整個資料夾就能分享。
  只有資料、不執行任何東西；寫錯的地方會列在設定頁，不會當掉。附範例「小雲朵」。
  格式見 [docs/custom-themes.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/custom-themes.zh-TW.md)。
- **自訂台詞**（#25）：在 `lines.json` 寫桌寵要說的話，依語言和事件（被點、額度提醒、AI 做完……）分組，可以和內建台詞混著說；
  記號打錯的那句會略過並在設定頁提醒。說明見 [docs/custom-lines.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/custom-lines.zh-TW.md)。
- **多帳號**（#26）：公司和個人帳號可以分開顯示。設定 → AI 服務 →「其他帳號」選另一個 Claude Code 設定資料夾（`CLAUDE_CONFIG_DIR`）
  或 Codex 資料夾（`CODEX_HOME`），每個都是一隻桌寵，名稱和顏色自己選。一樣不讀任何登入資料。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9457） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 2.16120.0（Claude Code 2.1.284）、Codex 26.924——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 684 項、桌寵自我測試 135 項、實機煙霧測試 9 項；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
