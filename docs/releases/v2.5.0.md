SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.5.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` → `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.5.0-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI` → `brew install --cask sentripet` |
| macOS Intel | `SentriPet-2.5.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.5.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`；自己下載的版本，結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **造型自帶台詞**（#28）：自訂造型的資料夾裡放一個 `lines.json`（寫法和自訂台詞一樣），換上這個造型時桌寵就會照每種心情說它的話，
  讓每個造型有自己的個性。你自己的台詞也照樣會說；寫錯的地方列在設定頁那個造型底下，造型照樣能用。
  範例造型「小雲朵」附上 5 種語言的台詞，會跟你聊天氣。
- **卡片上的文字也能依心情換**：文字元素可以像圖片一樣寫 `states`（額度很多、擔心、快沒了、用完、工作中……各一段），
  也可以每種語言各寫一份。格式見 [docs/custom-themes.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/custom-themes.zh-TW.md)。
- **修正：Claude 5 小時的重置時間卡在過去**。桌面版很久沒記錄時，5 小時額度跑完一輪後沒有接上下一輪，
  卡片一直顯示「即將重置」，用量也把一整天的 token 算進同一輪（回報的情況：顯示用了 86%，官方是 22%）。
  現在會一輪接一輪往後算、只算目前這一輪；在開發環境比對官方：5 小時 26.8%（官方 28%）、同樣 20:20 重置。
- **修正：自訂造型的方塊用 `provider`、`level` 這類會變的顏色時沒有上色**（說明文件說可以，2.4 起其實沒有作用）。
  現在卡片可以用每個 AI 的代表色當底色。

Claude 的用量是推算的：Claude 桌面版的 Code 分頁不會執行狀態列，官方數字只有在桌面版寫下紀錄（大多是啟動時）
或在終端機用 `claude` 時才拿得到，其他時候用 Claude Code 的 token 推算，誤差通常在幾個百分點內，重置時間是準的。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9457） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 2.26454.2（Claude Code 2.1.293）、Codex 26.1002——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 721 項、桌寵自我測試 139 項、實機煙霧測試 9 項；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
