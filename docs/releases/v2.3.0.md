SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.3.0-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` → `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.3.0-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI` → `brew install --cask sentripet` |
| macOS Intel | `SentriPet-2.3.0-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.3.0-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`；自己下載的版本，結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **用量報告**（#18）：右鍵選單 → 額度利用率 →「查看完整報告…」。最近 7 或 30 天每天用了多少 token（Claude Code 與 Codex）、
  專案排行、模型，以及每個週／月額度的利用率。只讀本機紀錄裡的數字、模型和資料夾名稱，不讀對話內容。
- **API 等值費用**（#19）：把 token 數乘上官方 API 價格，看看訂閱方案「幫你省了多少」。價格表附查詢日期與來源；
  設定資料夾放一份 `prices.json` 就能更新價格。只供比較，價格表上沒有的模型不會亂猜。
- **可分享的週報圖**（#20）：「產生這週的週報圖」會存一張 1200 × 675 的圖到「圖片／SentriPet」：這週的 token、API 等值費用、
  最常用的模型、額度利用率，加上你的桌寵。
- **系統匣直接顯示剩餘 %**（#21）：設定 → 外觀 開啟後，系統匣／選單列圖示就是最低的剩餘 %（綠／黃／紅）；
  也可以「只顯示在系統匣」，桌面上不放桌寵，點圖示再叫出來。
- **給其他程式用**（#22）：`usage.json`（每個 AI 的剩餘 %、重置時間、是否正在工作，有版本號），以及只在本機
  （`http://127.0.0.1:47291/`）的網頁，加到 OBS 的「瀏覽器來源」就有透明背景的用量條或桌寵。兩個都預設關閉。
  格式、選項與腳本範例見 [docs/usage-json.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/usage-json.zh-TW.md)。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9457） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 2.9939.4（Claude Code 2.1.284）、Codex 26.924——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 556 項、桌寵自我測試 113 項、實機煙霧測試 9 項（含真的用 HTTP 連本機網頁）；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
