SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.5.1-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` → `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.5.1-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI` → `brew install --cask sentripet` |
| macOS Intel | `SentriPet-2.5.1-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.5.1-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.x 升級：Scoop 用 `scoop update sentripet`、Homebrew 用 `brew upgrade --cask sentripet`；自己下載的版本，結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **修正：Codex 更新後，原本的通知程式不再執行**（#29）。開啟「AI 做完或在等你時提醒」時，SentriPet 會接手 Codex 的
  `notify` 並記下原本的通知程式、之後照樣執行。Codex 桌面版的通知程式（`codex-computer-use.exe`）放在一個每次更新都會換掉的
  版本資料夾裡，記下的路徑因此失效：Codex 每做完一次，記錄檔就多一行「找不到指定的檔案」，Codex 自己的通知也沒有執行。
  - 記下的程式所在的版本資料夾被換掉時，會到最新的版本資料夾找同一個程式；真的找不到就先不執行，設定頁會提示是哪個程式。
  - Codex 桌面版會把自己的通知程式放回最前面，再用 `--previous-notify` 執行 SentriPet。現在 SentriPet 認得這種寫法：
    設定頁照樣顯示已開啟、不會重複執行 Codex 的程式；關掉時只拿掉 SentriPet，Codex 自己的設定留著。
  - 不會再出現 SentriPet 和 Codex 的通知程式互相呼叫的情況（之前在這種狀態下重新打開開關就會發生）。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9457） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 2.26454.2（Claude Code 2.1.293）、Codex 26.1002——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 738 項、桌寵自我測試 139 項、實機煙霧測試 8 項；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證。
