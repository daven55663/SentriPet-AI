SentriPet 是放在桌面上的 AI 用量監控桌寵：自動偵測 Claude、Codex、Copilot 等 AI 工具，即時顯示還剩多少額度、多久後重置。
English: a desktop pet that shows how much of your AI plan is left — see the [README](https://github.com/daven55663/SentriPet-AI#readme).

## 安裝

| 系統 | 檔案 | 安裝 |
|---|---|---|
| Windows 10／11 | `SentriPet-2.7.1-win-x64.zip` | 解壓縮後執行 `SentriPet.exe`，或 `scoop bucket add sentripet https://github.com/daven55663/SentriPet-AI` 後 `scoop install sentripet` |
| macOS Apple 晶片（M1～M4） | `SentriPet-2.7.1-osx-arm64.zip` | `brew tap daven55663/sentripet https://github.com/daven55663/SentriPet-AI`、`brew trust daven55663/sentripet` 後 `brew install --cask sentripet`（Homebrew 現在要求先信任第三方 tap） |
| macOS Intel | `SentriPet-2.7.1-osx-x64.zip` | 同上 |
| Linux x64 | `SentriPet-2.7.1-linux-x64.tar.gz` | 解壓縮後執行 `./install.sh` |

從 2.7.0 升級：桌寵會自動詢問是否更新，按「現在更新」即可。更早的 2.x 版本沒有自動更新，請依上表手動更新——Scoop 用 `scoop update sentripet`、
Homebrew 用 `brew upgrade --cask sentripet`，自己下載的版本結束舊版後用新檔案覆蓋即可。設定都會保留。

## 這一版的變化

- **修正：Claude 桌面版更新後讀不到用量**（#40）。Windows 商店版的 Claude 桌面版從 5.1231 起把資料搬到 `%LOCALAPPDATA%\Claude-Data`，
  桌寵仍在舊的資料夾尋找用量紀錄，因而一直顯示「找不到用量紀錄：請開啟 Claude 桌面版」。現在新舊兩個位置都會尋找，並讀取較新的那份紀錄；
  紀錄的格式沒有改變，更新後就會恢復顯示。

## 開發與測試環境

| | |
|---|---|
| CPU | Intel Core Ultra 7 265KF（20 核／20 執行緒） |
| 記憶體 | 64 GB |
| 顯示卡 | NVIDIA GeForce RTX 5070 Ti（SentriPet 預設用 CPU 繪製，不使用顯示卡） |
| 螢幕 | 3 台 1920×1080，縮放 100% |
| 作業系統 | Windows 11 專業版 25H2（組建 26200.9711） |
| 開發工具 | .NET SDK 10.0.401（執行階段 10.0.12）、Avalonia 12.1.3、Git 2.55、GitHub CLI 2.101 |
| AI 工具 | Claude 桌面版 5.1231.2.0（Claude Code 2.1.322）、Codex 26.1106——也是本版讀取用量的來源 |
| 開發方式 | 使用 Claude Code（Claude Opus 5.5）開發 |
| 自動測試 | 核心 866 項、桌寵自我測試 158 項、實機煙霧測試 9 項，並在這台電腦以更新後的 Claude 桌面版實際讀到用量；GitHub Actions 在 Windows、macOS（Apple 晶片）、Linux 上各跑一次，四個安裝檔發佈前也各自跑過自我測試 |

完整的開發環境（含 CI 的系統映像）見 [docs/environment.zh-TW.md](https://github.com/daven55663/SentriPet-AI/blob/main/docs/environment.zh-TW.md)。
macOS 與 Linux 版在 CI 上通過自動測試，還沒有在實體電腦上長時間試用；遇到問題歡迎[開 issue](https://github.com/daven55663/SentriPet-AI/issues/new)。

本程式只在本機讀取用量資料，不讀取、也不傳送任何登入憑證；檢查新版本時只向 GitHub 查詢最新的版本號。
